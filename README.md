# ADV carts

Online cartridges for **ADV**, a little fantasy console.

ADV's cart library reads `index.json` and downloads carts from `carts/`.
Every `.adv` file is a real PNG picture - rename it to `.png` to see the game hidden inside.

Play them at **https://ilikehomeassistant.github.io/adv-web/**

![Click a cart and it runs down the ribbon into the console](https://ilikehomeassistant.github.io/adv-web/demo.gif)

## Your game could be here
There are only a handful of carts so far, so a new game gets noticed. You don't need to know
how to code: the Developer Kit's game kit makes a platformer from a few sprites and a map.
Stuck for an idea? Look at the [cart ideas](https://github.com/Ilikehomeassistant/adv-carts/issues?q=is%3Aissue+is%3Aopen+label%3A%22cart+idea%22),
or say hi in [Discussions](https://github.com/Ilikehomeassistant/adv-carts/discussions).

## Adding a cart
Make a game in the [Developer Kit](https://ilikehomeassistant.github.io/adv-web/devkit.html) and type
**UPLOAD** (or press **UPLOAD TO ADV ONLINE**), or send a pull request by hand. See [CONTRIBUTING.md](CONTRIBUTING.md).
